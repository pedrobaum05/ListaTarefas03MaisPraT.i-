# Lista de Tarefas 03 - +PraT.I

Exercícios práticos de JavaScript com foco em Objetos, Arrays e Estruturas de Dados.

## Conteúdos Abordados

- Objetos e `for...in`
- Arrays de objetos com `for...of` e `forEach`
- Estruturas de dados: Pilha, Fila e Lista Ligada

## Exercícios

### Objetos com for...in

| # | Descrição |
|---|---|
| 01 | Objeto produto com percorrimento e cálculo de desconto |
| 02 | Dois personagens comparando poder total |
| 03 | Funcionário com cálculo de bônus por anos de experiência |
| 04 | Inventário de jogador com uso de itens |
| 05 | Orçamento mensal com saldo geral |

### Arrays de Objetos com for...of e forEach

| # | Descrição |
|---|---|
| 06 | Músicas com duração em mm:ss e total geral |
| 07 | Alunos com classificação e média por grupo |
| 08 | Produtos com relatório de estoque e total geral |
| 09 | Contatos com listagem e busca por nome |

### Estruturas de Dados

| # | Descrição |
|---|---|
| 10 | Pilha — histórico de navegador (push/pop) |
| 11 | Fila — atendimento de clínica (push/shift) |
| 12 | Lista Ligada — gerenciador de tarefas (nós encadeados) |

## Como Rodar

**Pré-requisito:** Node.js instalado

```bash
node tarefa03.js
```

## Tecnologias

- JavaScript (Node.js)
- prompt-sync

## O que Aprendi

- Entendi como objetos funcionam e como percorrê-los com `for...in`
- Aprendi a diferença entre Pilha (LIFO) e Fila (FIFO) na prática
- Consegui montar uma Lista Ligada do zero usando nós encadeados
- Entendi quando usar `for...of` e `forEach` em arrays de objetos
